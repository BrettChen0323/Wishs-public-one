# 元旦回忆录

一本能自己写、自己贴照片、生成二维码送人的电子回忆录。单文件、零外链，断网也能打开。

## 线上地址

- 当前能打开的版本：**https://brettchen0323.github.io/Wishs-public-one/zx/**
- 根地址 `https://brettchen0323.github.io/Wishs-public-one/` 目前 404：根目录还没有 `index.html`。
- `ch/`、`public/` 里各有一个网页，但文件名是 `index (1).html`、`index (2).html`，所以 `.../ch/`、`.../public/` 也 404。把文件改名为 `index.html` 就能打开。

## 这本书的结构

8 页 = 4 个跨页，封面另算：

| 跨页 | 左页 | 右页 |
| --- | --- | --- |
| 1 | 扉页：书名、年份、题献、署名 | 引言 |
| 2 | 照片 01 | 写给妈妈 |
| 3 | 照片 02 | 写给阿哲 |
| 4 | 照片 03 | 写给小满 |

照片下没有配文；照片页只留 PLATE 编号和一枚小印。书名、年份、题献、署名、引言、三张照片、三个称呼和三段祝福都能改。

## 怎么看

- 封面：点印章或书的任意位置打开。
- 桌面：拖页面外侧边缘，或拖右下角页角；`←` `→` 和底部按钮也能翻。
- 手机：左右滑动，或点底部箭头。手机是 358×480 的双页小书。
- 合上：底部「合上」或 `Esc`。
- 阅读时文字和图片不响应鼠标，避免翻页时误选；要改内容先点「编辑」。

## 怎么改

1. 点底部「编辑」。
2. 点文字直接改：书名、年份、题献、署名、引言、称呼、祝福。
3. 点照片框放照片，或把图片拖进相框；照片会压到 1600px 内再存。
4. 改完再点一次「编辑」退出；内容自动保存在当前浏览器。
5. 「设置」里可以改书名、年份、署名、题献、引言，也可以导出备份、导出可发布版、导入备份、清空本机内容。

## 更新到线上

GitHub Pages 读的是仓库里的静态文件，不读你浏览器里的草稿。改完必须重新导出：

1. 在本地打开 `index.html`，改好内容。
2. 设置 →「导出备份」（建议，留一份 JSON）。
3. 设置 →「导出可发布版」，下载新的 `index.html`。
4. 到 GitHub 仓库，选一种放法：
   - **放根地址**：上传到仓库根目录，文件名 `index.html`；`https://brettchen0323.github.io/Wishs-public-one/` 就是新版。
   - **保留 `/zx/`**：上传覆盖 `zx/index.html`；`/zx/` 的网址和二维码不变。
   - **`ch/`、`public/`**：把里面的文件改名为 `index.html`；否则这两个路径继续 404。
5. 等 1–2 分钟，手机强制刷新。

## 二维码

- 打开要分享的那一版网址，点底部「分享」。
- 弹窗会自动填入当前网址，生成二维码；可以下载 1080×1440 的二维码卡片。
- 每版二维码不同，因为网址不同。
- 本地 `file://` 打开时没有可分享网址，先部署再生成。

## 多版本

一个版本 = 一个文件夹 + 一份导出的 HTML + 一个二维码。

1. 每版先「导出备份」JSON，再「导出可发布版」`index.html`。
2. 仓库里一版一个文件夹，例如 `01-mama/index.html`、`02-friends/index.html`。
3. 开 Pages 后，每版一个网址和一个二维码。
4. 本地一次只留一个草稿；切版前「清空本机内容」或「导入备份」。
5. 已发布页读到的是 HTML 里的 seed；本机草稿优先，顶部「回到发布版」可重置。

## 本机草稿的坑

GitHub Pages 的本地草稿按域名存，不按文件夹分。同一个浏览器先开 `/zx/` 再开 `/ch/`，可能看到上一版的草稿；点顶部「回到发布版」就显示当前页面的 seed。朋友的浏览器里没有草稿，不受影响。做版时一版一版来，每版先导出备份。

## 隐私

- 没有账号、没有统计、没有第三方请求。
- 文字和照片只存在浏览器 IndexedDB，失败时退回 localStorage。
- 只有你主动上传到 GitHub，内容才会上网。
- 二维码、导出 HTML、二维码卡片都在本地生成。

## 常见问题

**根地址 404？**  
根目录没有 `index.html`；上传一份到根目录。

**`/ch/` 或 `/public/` 404？**  
里面的文件名不是 `index.html`；改名。

**`/zx/` 能开但内容是旧的？**  
覆盖 `zx/index.html`。

**二维码是空白？**  
本地 `file://` 下没有网址；先部署。

**手机还是旧版？**  
等一分钟，强制刷新。

**照片刷新后没了？**  
无痕模式或禁用站点数据；先在设置里导出备份。
