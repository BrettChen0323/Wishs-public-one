元旦回忆录
一本能亲手写、亲手贴照片、还能生成二维码送人的电子回忆录。
打开是一本悬浮在纸色背景上的米色日记本，封面有一枚朱红印章。点开印章，封面翻开，进入一本双面摊开的纸本：左边一页放照片，右边一页写祝福。桌面上可以拖页边、拖页角翻页；手机上也保持双页，左右滑动。整本书只有一个 `index.html`，没有外链、没有后端，断网也能打开。
![封面](preview/01-cover.png)
先看它
双击 `index.html`。建议用 Chrome、Edge、Safari 或 Firefox 的较新版本。
封面：点印章或书的任意位置打开。
桌面：把鼠标放到页面外侧边缘，指针变成手形后左右拖；也可以拖右下角的页角，或用 `←` `→`、底部按钮、`扉页`。
手机：左右滑动，或点底部箭头。
合上：底部 `合上` 或 `Esc`。
阅读时文字和照片不响应鼠标：这是故意的，避免翻页时误选、误拖图片。要改内容，先点「编辑」。
第一次打开是 2027 年元旦的示例内容，可以全部换成你自己的。
![翻开](preview/02-open.png)
这本书的结构
8 页 = 4 个跨页，封面另算：
左：扉页（书名、年份、题献、署名）｜右：引言
左：照片 01｜右：写给妈妈
左：照片 02｜右：写给阿哲
左：照片 03｜右：写给小满
照片下面没有配文；照片页只留 PLATE 编号和一枚小印。书名、年份、题献、署名、引言、三张照片、三个称呼和三段祝福都可以改。
换照片、改文字
点底部的「编辑」，或在手机底部点铅笔图标。
点任意一段文字直接改。书名、年份、题献、署名、引言、称呼、祝福语都可以。
点照片框里的「放一张照片」或「换照片」，选一张图。也可以把图片直接拖进相框。
改完再点一次「编辑」退出。所有改动会自动保存在当前浏览器里，刷新还在。
照片会先压到最长边 1600px 的 JPEG，再存进浏览器。原图不会上传到任何地方。
书名、年份、署名、题献、引言也可以在上方「设置」里改。
![照片与祝福](preview/03-memory.png)
手机上的双页
手机不是把桌面页缩小，而是单独排的一本 358×480 的小书：左右各 179，字大约 9–10px，仍是左照片、右祝福。左右滑动，或拖页边/页角翻页；页面外侧边缘有 22px 的拖动热区。390 宽的手机能完整看到两页，320 宽会把「扉页」「分享」两个按钮收进菜单，只留前后、编辑、合上。
![手机双页](preview/04-mobile.png)
发到 GitHub Pages，用二维码送人
这本书是纯静态的，只要把 `index.html` 放到 GitHub Pages 就能用手机扫码打开。
在 GitHub 新建一个公开仓库，例如 `new-year-memoir`。
把「导出可发布版」下载的 `index.html` 上传到仓库根目录。文件名必须是 `index.html`。
打开仓库的 Settings → Pages。
Build and deployment → Source 选 `Deploy from a branch`。
Branch 选 `main`，目录选 `/ (root)`，点 Save。
等一两分钟。页面顶部会出现 `https://你的用户名.github.io/new-year-memoir/`。
用手机打开这个地址，点「分享」，二维码会自动填入当前网址。可以下载一张 1080×1440 的二维码卡片，发到群里或印在贺卡上。
二维码只编码你当前打开的网址，不会上传任何内容。本地双击打开时还没有外网地址，分享面板会提示先部署。
以后更新内容
GitHub Pages 不会读取你浏览器里的草稿，所以更新要走一次「导出」：
在本地或已发布的页面里改好内容。
打开「设置」，点「导出可发布版」。
会下载一个新的 `index.html`，照片和文字都已经烘焙进去。
用这个文件替换 GitHub 仓库里的 `index.html`，提交。
等一分钟，原来的网址和二维码都不变，刷新就能看到新版。
注意：直接上传最早那份 `index.html` 只会显示示例内容。要发布你自己的版本，一定用「导出可发布版」下载的文件。
做多个版本，发给不同的人
可以。每个版本是一份独立的 `index.html`，放在同一个仓库的不同文件夹里，各有一个网址和一个二维码。内容互不影响。
推荐这样操作：
先做第一版：打开 `index.html`，写完照片和祝福，点「设置 → 导出备份」留一份 JSON，再点「导出可发布版」下载 `index.html`。
建文件夹：在仓库里建 `01-mama/index.html`、`02-friends/index.html`。每个文件夹放一份对应版本的 `index.html`。用英文或数字命名文件夹，网址更干净。
开 Pages：仓库 Settings → Pages 选 `main` / `(root)`。等一两分钟。
拿网址：第一版是 `https://你的用户名.github.io/仓库名/01-mama/`，第二版是 `.../02-friends/`。
分别扫码：打开每一版的网址，点「分享」，会生成指向该网址的二维码；下载对应的二维码卡片。
换版本：本地一次只保留一个草稿。切到下一版前，在「设置」里点「清空本机内容」，或者「导入备份」导入那一版的 JSON。
发布版与草稿：好友打开网址看到的是那份 `index.html` 里烘焙的 seed；你在本机改的内容只存在你的浏览器里。如果打开已发布页时看到「正在看本地副本」，点「回到发布版」就能回到文件里的版本。
一句话：一个版本 = 一个文件夹 + 一份导出的 HTML + 一个二维码。改哪一版，就重新导出哪一版的 HTML，替换对应文件夹里的文件。
分享与备份
分享：生成当前网址的二维码，可下载二维码卡片。二维码在本地生成，不经过任何服务器。
导出备份：在「设置」里导出 `元旦回忆录-备份.json`，包含文字和照片，可以换设备导入。
导入备份：在「设置」里选备份文件恢复。旧版备份（4 段回忆）会自动迁移成 3 组「照片 + 祝福」，第 4 段会丢弃。
回到发布版：如果当前页面是从 GitHub 打开的，而你又在本机改过，顶部会出现一条提示，点「回到发布版」可以丢掉本地草稿，重新读取页面里烘焙的内容。
清空本机内容：在「设置」最下面，清掉这个浏览器里的草稿和照片。
照片多的时候，导出的 HTML 会变大。GitHub 单个文件上限是 100MB，正常几张照片远不到。
隐私
没有账号、没有统计、没有第三方请求。
文字和照片只存在你的浏览器 IndexedDB 里，失败时退回 localStorage。
只有你主动上传到 GitHub Pages，内容才会出现在网上。
二维码、导出 HTML、二维码卡片都在本地生成。
无痕模式或禁用站点数据时，刷新后可能留不住内容。重要内容请先「导出备份」。
文件说明
```
元旦回忆录/
├─ index.html          ← 唯一需要部署的文件，单文件、零外链
├─ README.md
├─ preview/            ← 预览截图，不参与部署
├─ src/
│  ├─ page.html        ← 开发用：HTML + CSS 模板
│  └─ app.js           ← 开发用：交互、存储、导出、二维码
├─ qr.js               ← 开发用：无依赖二维码编码器
├─ build.mjs           ← 开发用：把模板、样式、脚本合成 index.html
└─ make-test.mjs       ← 开发用：生成截图用的测试页
```
部署时只需要 `index.html`。`src/`、`qr.js`、`build.mjs` 是方便以后改源码的，不影响打开。
重新构建：
```bash
node build.mjs
```
本机没有全局 Node 时，可以用 DeepSeek Harness 自带的 Node：
```bash
"$DSH_NODE_EXECUTABLE" build.mjs
```
一些实现细节
桌面是 960×640 的双面书：左边固定为扉页，右边固定为最后一页祝福；中间 3 张 leaf，每张正面是右页、背面是左页。翻页时 `--turn` 从 0° 到 180°，页面外侧有卷边渐变和投影，翻到一半时能看到下一张的正面。
手机是 358×480 的双面小书，复用同一套 leaf 和 `--turn`，只是页面宽度变成 179。滑动和拖页边都走同一个 `turnTo`。
纸张是三层：底色渐变 + 双尺度噪点 + 两层纤维细纹；页面外侧有 1px 纸边、书口有 3 条错位的页块线、书脊有阴影。没有用图片，全部是 CSS。
阅读模式 `.page{pointer-events:none; user-select:none}`，只有页边和页角恢复指针；`img` 禁用拖拽。编辑模式才恢复文字选择和图片点击。
背景是 Canvas 纸屑，鼠标推开纸屑，暖光跟随，书和植物有轻微视差；静止时纸屑慢慢落下。`prefers-reduced-motion` 下纸屑只画一帧，翻页直切，悬浮和印章呼吸停止。
编辑用 `contenteditable="plaintext-only"`，按回车在单行字段里会直接收笔。照片拖入、压缩、存储、导出都在浏览器里完成。
分享二维码是自写的 byte mode 编码器，EC level M，版本 1 到 10，容量约 213 字节。GitHub Pages 的网址远小于这个长度。
字体用系统字体栈：正文宋体/思源宋体，批注楷体，拉丁衬线。没有在线字体请求。
颜色只用了三种：`#F0DEBF` 纸、`#F6C12C` 金、`#B22A2A` 朱红，其余是纸色的深浅和墨色。
常见问题
打开只有封面，点不开？
用较新的 Chrome、Edge、Safari 或 Firefox。文件必须完整，不要只复制了半段 HTML。
照片刷新后没了？
可能开了无痕模式，或浏览器禁止了站点数据。先在「设置」里「导出备份」。
二维码扫出来是空白？
本地 `file://` 打开时没有可分享的网址。先按上面的步骤部署到 GitHub Pages，再从部署后的地址打开分享。
GitHub Pages 打开是 404？
确认文件名是 `index.html`，在仓库根目录（或对应版本文件夹），Pages 的分支和目录选对了，并且已经等了一两分钟。
更新了 GitHub 上的文件，手机还是旧版？
等一分钟，然后在手机上强制刷新。二维码指向的网址没有变。
想换标题或年份？
「设置」里改书名、年份（中文）、年份（数字）、署名、题献、引言。封面和扉页会一起更新。
能加第 4 张照片吗？
这一版固定 3 组「照片 + 祝福」，对应 8 页。要做第 4 组，复制一份 HTML，在源码里把 `entries` 加到 4 组，再重新排版；普通使用建议直接做第二本。
设计说明
视觉方向是「纸本回忆录」，不是通用落地页：米色纸、金线、朱印、宋体标题、楷体批注，单一悬浮物，慢动效。参考了 finesse-ui 的品牌基底和 Starbucks 设计规范里的暖纸纪律，但配色、结构、内容全部按这本书重做。
ThreeUI 的 `MengToSketchbookLandingPage` 只作为氛围参考：纸感、植物、翻页、可把玩的细节。没有复制它的组件、文案、图片或代码。
示例里的三组照片位、三句祝福、书名和年份都是占位内容，换成你自己的就好。
